# 🚀 SkillPath AI

### Stop Searching for Roadmaps. Start Following Yours.

**SkillPath AI** is an AI-powered adaptive career learning platform designed to help students move from **confusion → structured learning → measurable improvement → career readiness**.

Instead of giving every student the same static roadmap, SkillPath AI considers a student's **education, interests, career goal, current skills, diagnostic performance, weaknesses, available study time, DSA activity, and projects** to create a personalized learning journey.

---

## 🎯 Problem

Students today have access to thousands of learning resources, but too much information often creates another problem: **lack of direction**.

Students commonly:

- Spend hours searching for the "perfect" roadmap.
- Switch between YouTube videos, courses, blogs, GitHub repositories, and different roadmaps.
- Follow generic learning paths that do not match their current level.
- Learn topics they already know while missing important prerequisites.
- Finish courses without knowing whether they actually understood the material.
- Struggle to identify their exact weak areas.
- Forget previous weaknesses and repeat the same mistakes.
- Practice random DSA problems instead of targeting their weak topics.
- Miss coding contests because schedules are distributed across different platforms.
- Build random projects without understanding whether they align with their career goal.
- Lack clarity about the skills expected for their target role.

### The core problem

> Students don't need more roadmaps. They need a learning system that understands **where they are, where they want to go, and what they should do next**.

---

# 💡 Solution

SkillPath AI creates a **personalized and continuously adaptive learning path** for each student.

### Core learning loop

```text
Student Profile
       ↓

       ↓

       ↓
AI Skill Analysis
       ↓
Personalized Roadmap
       ↓
Learn
       ↓
Topic Assessment
       ↓
Weakness Detection
       ↓
Weakness History
       ↓
Targeted Revision
       ↓
Reassessment
       ↓

       ↓

       ↓

       ↓

```

The roadmap is not static.

As the student learns and gets assessed, **SkillPath AI continuously adapts what the student should focus on next**.

# ✨ Key Features

## 🧠 AI-Powered Personalized Roadmap

SkillPath AI generates a roadmap based on:

- Career goal
- Current skills
- Diagnostic assessment
- Skill gaps
- Prerequisites
- Available study time
- Learning preferences

A beginner and an intermediate student targeting the same role can receive different learning paths.

---

## 📝 AI Diagnostic Assessment

Before generating a personalized learning path, the platform evaluates the student's actual knowledge.

Assessment formats can include:

- Multiple-choice questions
- Code output
- Debugging
- Conceptual questions
- Scenario-based questions
- Practical reasoning

The results are used to build an initial verified skill profile.

---

## 🔍 AI Weakness Detection

SkillPath AI goes beyond a simple score.

Instead of only showing:

```text
Score: 62%
```

the system identifies the concepts where the student actually struggles.

Example:

```text
Java OOP

Inheritance      81%
Encapsulation    88%
Abstraction      55%
Polymorphism     42%   ← High Priority
```

The AI explains the likely source of the weakness and recommends targeted improvement.

---

## 📈 Weakness History

Weaknesses are stored over time so students can see whether they are improving.

Example:

```text
Polymorphism

Assessment 1 → 42%
Assessment 2 → 58%
Assessment 3 → 76%
```

Students can identify:

- Current weaknesses
- Recurring weaknesses
- Improving weaknesses
- Resolved weaknesses

---

## 🔄 Adaptive Roadmap

The roadmap changes based on actual performance.

Example:

```text
Poor assessment
      ↓
Weakness detected
      ↓
Topic priority increases
      ↓
Targeted revision
      ↓
Practice
      ↓
Reassessment
      ↓
Improvement
      ↓
Priority decreases
```

This turns a static roadmap into an **adaptive learning system**.

---

## 🎯 "What Should I Study Now?"

One of the core features of SkillPath AI.

Instead of making students decide what to study every day, the system considers:

- Current roadmap state
- Prerequisites
- Assessment history
- Weaknesses
- Recent activity
- Career goal
- Available study time

Example:

> **Revise Polymorphism for 45 minutes**

The recommendation also explains why that action was selected.

---

## 📅 AI Daily Study Planner

SkillPath AI generates a practical daily plan based on the student's available time.

Example:

```text
3 HOURS TODAY

45 min → Weakness Revision
45 min → Current Roadmap Topic
45 min → DSA Practice
30 min → SQL Practice
15 min → Assessment
```

If the student only has 90 minutes, the plan can be regenerated around that constraint.

---

## 💬 AI Mentor

The AI Mentor uses the student's actual learning context to provide personalized guidance.

Students can ask:

- What should I study today?
- Why am I weak in recursion?
- Can I skip this topic?
- What should I learn before Spring Boot?
- Give me problems based on my weaknesses.
- I missed three days. Rebuild my plan.
- Which project should I build next?

The mentor is designed to use the student's roadmap, assessments, weaknesses, and progress rather than acting as a generic chatbot.

# 🔗 Direct Coding Problem Links

Coding problems retain their original platform and URL.

For example:

```text

Platform: LeetCode

[ Open on LeetCode ]
```

A Codeforces problem opens on Codeforces, a CodeChef problem opens on CodeChef, and so on.

This keeps the actual problem-solving experience on the original platform while allowing SkillPath AI to organize and personalize recommendations.

Learning concepts is not enough. Students need to build projects that demonstrate those skills.

SkillPath AI recommends projects based on:

# 📊 Progress That Tells the Truth

A major design principle of SkillPath AI is **real progress**.

A new student starts with:

```text
Overall Progress       0%
Completed Topics       0
Assessments            0
Weaknesses             0
DSA Problems Solved    0
Projects Completed     0
Learning Hours         0
Study Streak           0
```

Generating a roadmap does **not** count as learning.

Opening a topic does **not** mean mastery.

Progress increases only from actual student activity stored in the database.

This ensures that the dashboard represents what the student has actually done.

---

# 🔐 Multi-User & Data Isolation

SkillPath AI is designed as a multi-user application.

Each student has an independent:

- Profile
- Roadmap
- Skill profile
- Assessments
- Weakness history
- DSA activity
- Projects
- Study plans
- Learning history

User A must never be able to access User B's data.

Authentication and server-side ownership checks are used to protect private student information.

# 🚀 Getting Started

## 1. Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/skillpath-ai.git
cd skillpath-ai
```

## 2. Install dependencies

```bash
npm install
```

If the project contains separate frontend and backend applications, install dependencies in each directory according to the project structure.

## 3. Configure environment variables

Create a `.env` file based on `.env.example`.

Example:

```env
DATABASE_URL="your_postgresql_connection_string"
GROQ_API_KEY="your_groq_api_key"
```

Add any other authentication or application variables required by the project.

**Never commit real API keys or secrets to GitHub.**

## 4. Set up the database

For Prisma-based projects:

```bash
npx prisma generate
npx prisma migrate dev
```

Use the project's actual Prisma migration/seed setup where applicable.

## 5. Start development server

```bash
npm run dev
```

Then open the local URL shown in the terminal.

# 🔑 Groq Configuration

SkillPath AI uses Groq for its AI functionality.

Configure the API key as a server-side environment variable:

```env
GROQ_API_KEY=your_key_here
```

The key should never be exposed to client-side JavaScript.

Groq powers features such as:

- Diagnostic analysis
- Personalized roadmap generation
- Topic assessment generation
- Weakness analysis
- Daily study plans
- Next-action recommendations
- Project recommendations
- Career analysis
- AI Mentor

Use a currently supported Groq model and keep the model configuration centralized so it can be updated without changing every AI service.
